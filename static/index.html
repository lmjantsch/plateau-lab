Raw Euclidean distance · final-token residual stream · no normalization

c(t) is the fraction of the sampled output trajectory’s total Euclidean path length accumulated up to t. Add the L2 distances between consecutive output vectors, then divide by the total across the complete trajectory. The denominator is fixed for the run and readout. Detours and backtracking count as movement.

c(tk) = Σi=1…k ‖zi − zi−1‖₂ / Σi=1…N ‖zi − zi−1‖₂

This is not a probability or the fraction of the straight-line distance to B. A zero-length trajectory has undefined c(t). Uniform path progress, c(t) = t, means constant accumulation per unit t; the output trajectory need not be straight. Measured path length depends on sample resolution.
